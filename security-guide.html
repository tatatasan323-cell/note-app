00まず、覚える4つ

パスキーでも守れない穴は、この4つでほぼ塞がる

パスキー（指紋・顔・PINでログインする仕組み）は、偽サイトにパスワードを入れさせる詐欺にとても強い仕組みです。それでも守れない穴が2つあります（01で説明します）。その穴を塞ぐために覚えることは、次の4つだけです。

1「コピーして貼って実行」「この手順で押して」と言われたら、無視して閉じる
2ソフトは公式サイトからだけ入手。検索の「スポンサー」「まとめ」「ブログ」サイトは利用しない
3警告画面に出た電話番号にはかけない、URLのリンクも押さない
4向こうから来た電話・SMS・メール・通知には、その場で応じない。自分から要求していないものは無視するか、自分で開き直す・かけ直す

01パスキーの強さと、2つの穴

偽サイトには強い。守れないのは「PCの中」と「自分の承認」

例えるなら、パスワードは「合言葉」です。偽の門番（偽のログイン画面）にも言えてしまいます。パスキーは、本物の扉の鍵穴にしか合わない「鍵」。スマホやPCの中から出ることはなく、指紋や顔もサイトには送られません。

強い

  • 偽サイトの詐欺
  • 使い回し・流出

守れない

  • PCの中のマルウェア
  • 急かされての承認

守れないのは、家の中にすでに泥棒がいるときと、騙されて、泥棒が持ってきた鍵を自分の家の合鍵として登録してしまうときです。前者は、PCに入り込んだマルウェアが、ログイン済みの「通行証」を盗む手口（03）。後者は、急かされて、攻撃者の端末を自分で承認してしまう手口（05）。どちらも、パスキーの暗号そのものは破られていません。

02入口の強さは、いちばん弱いところで決まる

パスキーと2段階認証は、両方そろえて意味がある

パスワードだけ✕偽サイトに弱い
＋2段階認証△転送で破られる
パスキー◎偽サイトで回らない

2段階認証は、パスワードのあとに、スマホに届く6桁のコードなども入れる仕組みです（「2要素認証」「多要素認証」とも呼ばれます）。パスワードだけよりずっと強くなりますが、パスワードもコードも画面に打ち込む情報なので、偽サイトに入れてしまえば、攻撃者がその場で本物のサイトへ転送して入れます（リアルタイムフィッシング）。パスキーは打ち込む情報を使わず、スマホ（持ち物）と指紋・顔・PIN（本人）を1回で確かめます。

ただし、パスキーを登録しても、多くのサービスではパスワードの入口も残ります。玄関に最新の鍵を付けても、勝手口が合言葉で開くなら、泥棒は勝手口から入ります。アカウントの強さは、残っている中でいちばん弱い入口で決まります。

PIN（短い番号）はパスワードより弱くないの？　PINは、その端末の中の鍵を開けるためだけに使われ、サイトには送られません。パスワードが「どの扉でも通じる合言葉」なら、PINは「自分のポケットの中の金庫の番号」です。弱点は、端末とPINを両方まとめて取られたとき。誕生日のような番号は避け、入れるときは画面を隠す。パスキーを同期しているGoogleやiCloudのアカウントにも、2段階認証をかけておきましょう。

こうする：
  1. パスキーを登録する
  2. 残るパスワードの入口にも、2段階認証をかける（パスワードでのログインを止められるなら、止める）
  3. パスワードの再設定に使うメールにも、同じ守りをかける
パスキーが使えるはずのサイトで、急に「別の方法でログイン」と出たら、立ち止まる。

一度ログインすると、ブラウザは「この人はもう確認済み」という通行証（Cookie）を持ちます。次から毎回パスワードを聞かれないのは、このおかげです。イベント会場の入場リストバンドと同じで、盗まれて他人に付けられたら、入口の確認はもう済んだ扱いになってしまいます。

1,861件
Cookie（1台あたり平均）
約937億件
闇市場に出回るCookie

マルウェアに感染したPC1台からは、平均でパスワード44件と、Cookie 1,861件が盗まれます（2025年の調査）。Cookieの多くはただのメモですが、中にはメールや仕事の道具に入ったままの通行証が紛れています。闇市場には約937億件のCookieが出回っていて（2025年）、今も使えるものは一部ですが、攻撃者はそこから選び出します。

攻撃者が欲しいのは、パスワードより通行証です。だから一番の防御は、マルウェアをPCに入れないこと。入口は、次の04の5つです。

04マルウェアの入口5つ

いちばん多いのは、自分の手で「貼って実行」させる手口

いま一番多い入口

A　偽のロボット確認 ── コマンドを貼らせる

ウェブページに本物そっくりの確認画面が出て、「確認のため、次の操作をしてください」と指示されます。言われたとおりにキーを押すと、自分の手でマルウェアを入れてしまいます。2026年は、この手口がメールの詐欺を抜いて最多の入口になりました。

偽物の例（実際の手口を簡略化）
私はロボットではありません
確認のため、次の3ステップを行ってください
  1. Windows ＋ R を押す
  2. Ctrl ＋ V を押す
  3. Enter を押す

この3つのキーは、「PCに命令を打ち込む窓を開く」「ページがこっそりコピーしておいた命令を貼り付ける」「実行する」という操作です。見知らぬ人が書いた命令書に、中身も読まずに自分でハンコを押すのと同じです。

こうする：本物のロボット確認は、キーボード操作を求めません。「貼って実行して」と言われたら、そのページを閉じる。Macの「ターミナルに貼って」も同じです。
入口

B　検索の広告 ── 偽のダウンロードページへ

検索結果のいちばん上に出る「スポンサー」（広告）の枠に、本物そっくりの偽サイトが並びます。

偽物の例（実際の手口を簡略化）
スポンサー
https://claude-code-install.example
Claude Code をインストール｜公式ガイド
1行のコマンドで、すぐに使えます。Windows・Mac対応。

2026年5月には、AIツール「Claude Code」の検索広告から偽のインストールページへ誘い、コマンドを実行させて情報を盗む手口が見つかりました。7月には偽の「Claudeデスクトップアプリ」でPCを遠隔操作する例、9月には人気ソフトの偽サイトから入れたインストーラーがWindowsの更新とウイルス対策を止める例が報告されています。

検索結果の「スポンサー」は、お金を払えば誰でも出せる広告の枠です。「公式」と書かれたチラシが、本当に公式とは限りません。

こうする：ソフトは、ブックマークした公式サイトか、公式のアプリストアから。検索結果の「スポンサー」や、まとめ・ブログに貼られたリンクからは入れない。
入口

C　偽の警告画面 ── 電話をかけさせる

突然、大きな音とともに「ウイルスに感染しています」という画面が出て、電話をかけさせます（サポート詐欺）。電話の先で遠隔操作ソフトを入れさせ、お金を取ったり、PCの中を見たりします。

偽物の例（実際の手口を簡略化）
警告：ウイルスに感染しています
個人情報が流出しています。PCの電源を切らないでください。
今すぐサポートにお電話ください。
0120-XXX-XXX

警察庁の集計では、2025年上半期だけで679件・被害額約8億5千万円。2025年12月から2026年5月には、この画面へ誘うメールが1,300万通以上観測されています。

こうする：表示された番号にかけない。遠隔操作ソフトを入れない。画面が消えなければ、ブラウザを閉じる。それでも消えなければ再起動。
入口

D　ブラウザの拡張機能

勤怠や会計などの業務ツールを名乗る偽の拡張機能が、通行証を盗んでアカウントを乗っ取る例が、2026年1月に見つかっています（5種類、2,300回以上インストール）。

こうする：拡張機能は必要なものだけ。業務用は会社が指定したものだけ。使っていないものは削除する。
入口

E　メール・SMS・SNSのリンクと添付

昔からある入口ですが、いまも現役です。上のA〜Cへの入り口にもなります。

こうする：身に覚えのない添付は開かない。大事なサービスは、リンクからではなく、ブックマークや公式アプリから開く。詳しくは次の05で。

05向こうから来た連絡には、その場で応じない

SMS・メール・通知・電話。頼んでいないものには応じない

毎日届くたくさんの通知に紛れて、攻撃者からの連絡も届きます。宅配業者・銀行・通販・役所・自社のIT部門など、本物の名前と本物そっくりの文面で来るので、見た目では見分けられません。

頼んでくるのは、この3つ

開かせるリンク・QR・添付
入れさせるパスワード・コード
押させる承認ボタン

リンクをタップさせる、QRコードを読ませる、添付を開かせる。パスワードや届いたコード、カード番号、個人情報を入力させる（電話で言わせる）。「サインインしようとしていますか？」の承認ボタンを押させる。

向こうから来た連絡の中では、この3つを一切しない
偽物の例（実際の手口を簡略化）
SMS
【宅配便】お荷物をお届けに上がりましたが、不在のため持ち帰りました。再配達のご依頼はこちら
https://redelivery.example
メール
【重要】アカウントを一時停止しました
24時間以内に本人確認を完了しない場合、ご利用いただけなくなります。
本人確認へ進む
アプリの通知
サインインしようとしていますか？
場所：不明 ／ 端末：Windows
承認拒否

急がせる電話で、自分で承認させる手口

1

個人の携帯に電話・SMS

2

偽のログイン画面へ

3

コードを入れて承認

4

以後、いつでも入られる

マルウェアを使わない手口もあります。2026年5月から、社内のIT部門を名乗る電話で、社員に攻撃者の端末を承認させる手口が観測されています。「IT部門です。パスキーを今すぐ更新しないと、使えなくなります」と急かされ、SMSで届いた本物そっくりの画面にコードを入れた瞬間、攻撃者の端末が「あなた」として登録されます。以後は何もしなくても入られ、メールやファイルを何日もかけて静かに抜かれます。急がせる、偉い立場を名乗る、確かめる暇を与えない。昔からある「オレオレ詐欺」と同じ台本です。

では、どうするか

  • 確かめたいときは、その連絡からではなく、自分で開き直す。ブックマーク、公式アプリ、いつも使っている電話番号から。本当の用件なら、そちらにも同じ知らせが出ています。
  • 急がせる電話は、一度切って、社内の番号【IT部門の番号を記載】へ自分でかけ直す。本物のIT部門は、急がせません。
  • 届いたコードは、誰にも教えない。本物の会社やIT部門が、電話やメッセージでコードを聞くことはありません。
  • 心当たりのない承認は「拒否」。何度も届くなら、誰かがあなたのパスワードを知っている合図です。別の安全な端末からパスワードを変え、会社なら【担当窓口】へ。
  • 知らないサイトの「通知を許可しますか？」は、許可しない。許可すると、04のCのような偽の警告が、通知で届くようになります。
例外は1つだけ：自分がいま、公式サイトや公式アプリでログインしていて、その続きとして届いたコード。それ以外は、応じない。

06知っておくだけでよい弱点

パスキーの周りの弱点も、先にPCに入られていることが前提

2026年8月、専門家がパスキーの周辺の弱点をまとめて発表しました。

  • Chromeで同期しているパスキー：PCに入り込んだマルウェアが同期用の親鍵を抜き取れば、パスキーを復元できた（Googleは記録を止めたが、親鍵を作り直す手段はまだ無い）
  • Windows Hello：PCに入り込んだマルウェアが、PINや顔認証の確認なしに鍵を使えた
  • Windowsの記録：使用済みの認証を記録から拾って使い回せた（Microsoftは7月の更新で対処）

パスキーの暗号そのものは破られていません。だから、入れないこと。そして、Windowsとブラウザの更新を止めないこと。

07やめること・やること

迷ったら、この表だけ見ればよい

やめる代わりに
画面の指示で、キーを押して何かを「貼って実行」するそのページを閉じる
検索結果の「スポンサー」からソフトを入れるブックマークした公式サイト・公式ストアから入れる
警告画面に出た番号へ電話するブラウザを閉じる。消えなければ再起動
便利そうな拡張機能を入れる会社が指定したものだけ。使わないものは消す
SMS・メール・通知のリンクを開く、QRコードを読む開かない。公式アプリ・ブックマークから自分で開く
急がせる電話・SMS・メール・通知の指示に、その場で従う一度閉じる・切る。知っている番号や公式アプリから、自分で確かめる
届いたコードを、人に教える誰にも教えない。本物は、コードを聞かない
身に覚えのないコード入力・承認をする「拒否」を押す。IT部門へ知らせる
知らないサイトの「通知を許可」を押す許可しない
パスキーを登録して安心し、パスワードの入口を放っておく残るパスワードにも2段階認証。止められるなら止める
「あとで」と更新を先延ばしにするWindows・ブラウザの更新は、その日のうちに

08会社でAIを使う場合（管理者の方へ）

騙される前提で、権限は小さく、押すのは人

AIは、読んだ文章の中の指示と、ただのデータを区別できません。どんなに優秀でも、騙されやすい新人に、いきなり金庫の鍵と会社の印鑑は預けないのと同じ考え方で囲います。

  • AIには専用のアカウントを作り、見せるのは必要なフォルダだけ、まずは「閲覧だけ」。管理者の権限は渡さない（AIが自分の記録を消せないように）
  • メール送信・公開・支払い・削除・社外への共有は、AIは下書きまで。押すのは人。「実行の前に毎回確認」の設定を「全部許可」にしない
  • AIのサービスに、利用上限と予算アラートを設定する。アラートは担当者のメールへ。月に1回、請求を先月と並べて見る

09もし、やってしまったら

まず切る、すぐ知らせる、別の端末で変える

  1. ネットを切る。Wi-Fiをオフにする、LANケーブルを抜く
  2. 会社のPCなら、すぐ【担当窓口】へ。自分で直そうとしない
  3. 別の安全な端末から、大事なアカウントのパスワードを変え、「すべての端末からログアウト」を選ぶ
  4. お金が絡むなら、カード会社・銀行へ連絡。警察への相談は #9110（警察相談専用電話）

恥ずかしいことではありません。どれも、よく作られた手口です。早く言うほど、被害は小さくなります。
